## Wichtiger Hinweis des Designers
Das Modell ist eine **rein statische Deko-Requisite**: kein Schussmechanismus,
keine beweglichen Funktionsteile, nicht als Waffe nutzbar. Für den Tagger
muss das Gehäuse selbst ausgehöhlt/angepasst werden, um ESP32-S3, Akku,
IR-LED, MOSFETs, WS2812, Lautsprecher etc. unterzubringen (siehe
[readme.md, Abschnitt 10 "Offene Punkte"](../../readme.md#10-offene-punkte)).
Nutzer-Reviews weisen zudem auf schwer
entfernbare Supports und knappen Platz hin – beim Druck/Zusammenbau beachten.
